# CUT API-keys, rate limits & metering

- **Aanmaken/lijst/intrekken**: `POST|GET|DELETE /api/v1/keys` — alleen met Suite-browsersessie (aal2). Org = Suite-user-id. Body: `{name, scopes?, rate_limit_per_min?, budget_eur_month?, budget_units_day?}` (budgets `null` = onbeperkt). De sleutel (`cut_live_…`) wordt **één keer** getoond. Admin zonder browser: `bun scripts/agent/create-key.ts --org <id> --name "Klant"`.
- **Opslag**: alleen `sha256(key)` + prefix. Supabase (`agent_api_keys`, schema `apps/web/src/lib/agent-keys/schema.sql`, service-role, RLS aan zonder policies) als `CUT_SUPABASE_SERVICE_ROLE_KEY` + `NEXT_PUBLIC_SUPABASE_URL` gezet zijn; anders bestandsstore in `CUT_AGENT_KEYS_DIR` (default `./.agent-keys`, keys.json + usage.jsonl — op Coolify een volume mounten).
- **Scopes**: `media:read media:write render transcribe voice editor publish` (`publish` = `publish_to_social`, alleen concept; bestaande keys hebben het niet). Tool→scope staat in `tools.ts`.
- **Rate limit**: per key, vaste minuut-window in-memory (default 60/min, max 600), `429` + `Retry-After`.
- **Budget** (v2): per key `budget_eur_month` + `budget_units_day`; admin: `bun scripts/agent/create-key.ts --org X --budget-eur-month 25 --budget-units-day 500`. Overschrijding: 402/429 met duidelijke melding, zie `MCP.md`. `GET /api/v1/usage` toont totalen (factureerbaar: final/accepted/auto_accepted), `by_state` (pending/voided apart) en `budget` van de key.
- **Usage-events** (append-only, 1 per call, ook bij fouten met `units:0`): `{id, key_id, org, tool, units, eur, unit, state, ref?, ts, status, ms, channel}`. `units` = factureerbare eenheden uit `pricing.json` (export_min, transcribe_min, vo_1k_chars; gratis tools 0), `eur` = units x PAYG-tarief (CONCEPT). `state`: `final`, `pending` (render wacht op `accept_export`), of resolutie-event `accepted`/`voided` met `ref`. Pending zonder resolutie telt na 24 u als geaccepteerd (leeslaag, nooit UPDATE). Tabel `agent_usage_events` (trigger blokkeert update/delete) of `usage.jsonl`. Oude events (units = gewicht, geen `eur`) blijven leesbaar als `final` met EUR 0.
- **Supabase-migratie v2**: `apps/web/src/lib/agent-keys/schema-v2-budget-accept.sql` (additief, idempotent, view `agent_usage_billable`). **NIET toegepast**; eerst toepassen, dan pas de nieuwe code deployen (de usage-insert schrijft de nieuwe kolommen).
- **Env**: `CUT_APP_URL` (links in resultaten), `CUT_ENGINE_URL`, `CUT_AGENT_KEYS_DIR`, `CUT_SUPABASE_SERVICE_ROLE_KEY`. Geen DB-wijzigingen gedaan.
